# FEAUTURES

Design ideas, layouts and effects, in one place. Not a food website: no food photos, products or prices.

Five design sources, fetched deep and built in: Figma's 13 web design trends for 2026 plus 4 AI trends; Tilda's 9 core web design styles; Refero Styles' library of 2,000+ design systems and DESIGN.md workflow; UI/UX Pro Max's design-intelligence database (styles, palettes, font pairings, chart types, landing patterns, UX guidelines, tech stacks); and Dribbble's website-template patterns (inspiration only, stale March 2025 copy — never copy shots, branding, images or code).

Plus every Motion+ effect as an original equivalent built with the free, MIT-licensed Motion library: Gallery (now layout wireframes), Carousel, Ticker, Cursor, AnimateNumber, AnimateText, Typewriter, ScrambleText, AnimateView, Curtains, splitText. Motion+ is a paid membership; this site has no Motion+ access and uses no Motion+ source. AnimateActivity (early access) is not demonstrated. All motion is static under `prefers-reduced-motion`, and the ticker and carousel pause on hover and focus.

React + Vite + TypeScript + Tailwind CSS + Motion. Run `npm install`, then `npm run dev`. Build with `npm run build`.

## Open source section

All open-source items from the website-build toolkit, checked live on GitHub on 29 October 2026 (repo, licence, stars, last push). Live demos, loaded lazily: GSAP 3.13 timeline + ScrollTrigger scrub, Anime.js 4.1 stagger, Lenis 1.3 smooth scroll. Everything else is a catalogue entry with its GitHub link, including Motion, Three.js, Lottie, Barba.js, Tailwind, shadcn/ui, Radix Colors, Lucide, Heroicons, Feather, Fontsource, Open Design, Agent-Reach, the Muse 3D repos, starters, and the awesome lists.
