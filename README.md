# FEAUTURES

Motion effects, live. Every effect from the Motion+ feature table, built as an original equivalent with the free, MIT-licensed Motion library — Gallery, Carousel, Ticker, Cursor, AnimateNumber, AnimateText, Typewriter, ScrambleText, AnimateView, Curtains, and splitText — plus the five web design resources (Figma trends, Refero Styles, Tilda styles, UI/UX Pro Max, Dribbble templates).

Motion+ is a paid membership. This site has no Motion+ access and uses no Motion+ source, private GitHub, or paid API. AnimateActivity (early access) is not demonstrated. All motion is static under `prefers-reduced-motion`, and the ticker and carousel pause on hover and focus.

React + Vite + TypeScript + Tailwind CSS + Motion. Run `npm install`, then `npm run dev`. Build with `npm run build`.
